# Ronald (glitchbytez) — portfolio

A static, single-page portfolio. Plain HTML, CSS and a little vanilla JavaScript: no framework, no build step.

## Run locally

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

(Opening `index.html` directly from disk won't load `content.json`; use a local server.)

See `PORTFOLIO_SPEC.md` for the full spec.
